クラウド保存（Firebase）設定
設定すると全員でデータを共有できるようになります。1回だけの作業です。
📡 現在の接続状況
確認中...
⏱ 設定作業は10〜15分ほどかかります。スマートフォンよりパソコンで行うと簡単です。
1Firebaseにアクセス
  • 下のリンクをタップして Firebase Console を開く
  • Googleアカウント（yoshimi.smc.fc@gmail.com）でログイン
🌐 Firebaseを開く
2プロジェクトを作成
  • 「プロジェクトを追加」をクリック
  • プロジェクト名：yoshimi-smc-portal と入力
  • Googleアナリティクス：「無効」でOK
  • 「プロジェクトを作成」→「続行」
3Realtime Databaseを作成
  • 左メニューの「構築」→「Realtime Database」をクリック
  • 「データベースを作成」をクリック
  • ロケーション：Asia (asia-southeast1) を選択
  • 「テストモードで開始する」を選択 → 「有効にする」
⚠️ テストモードは30日で期限切れになります。期限切れになったら「ルール」タブで読み書き許可の日付を延長してください。
4セキュリティルールを設定
  • Realtime Database 画面の「ルール」タブをクリック
  • 下記のルールをコピーして貼り付ける
{ "rules": { ".read": true, ".write": true } }
  • 「公開」ボタンをクリック
5アプリを登録して設定値を取得
  • 左メニューの「プロジェクトの概要」をクリック
  • 「</>」（ウェブ）アイコンをクリック
  • アプリのニックネーム：portal と入力
  • 「アプリを登録」をクリック
  • 表示されたコードの中から下記の値をコピーする
const firebaseConfig = { apiKey: "AIzaSy...", ← これをコピー authDomain: "yoshimi-smc-portal.firebaseapp.com", databaseURL: "https://yoshimi-smc-portal-default-rtdb.firebaseio.com", projectId: "yoshimi-smc-portal", storageBucket: "yoshimi-smc-portal.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abc..." };
6firebase-config.js に設定値を入力
  • GitHubの下記ファイルを開く：
    ✏️ firebase-config.js を編集
  • YOUR_API_KEY などの部分を
    STEPで取得した実際の値に書き換える
  • 「Commit changes」をクリックして保存
✅ 数分後にサイトが更新され、この画面の「接続状況」が緑に変わります！
💡 設定が分からない場合はClaude（このアプリを作ったAI）に
「Firebaseの設定値をfirebase-config.jsに入れてください」と送ってください。
