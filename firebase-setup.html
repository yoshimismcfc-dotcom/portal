クラウド保存（Firebase）設定
ログインなしでFirebaseへ読み書きする公開モードの設定です。
📡 現在の接続状況
確認中...
この公開モードでは、URLを知っている人は名簿・会計などを閲覧・変更できます。設定前にRealtime Databaseのバックアップを取得してください。
1Firebaseプロジェクトを確認する
  • Firebase Consoleで yoshimi-smc-portal を開く
  • Realtime Databaseのデータをバックアップする
Realtime Databaseを開く
2公開用Database Rulesを反映する

このリポジトリの database.rules.json が公開用ルールです。Firebase CLIで次を実行します。

firebase login firebase use yoshimi-smc-portal firebase deploy --only database
ルートの読み取り・書き込みを許可するため、URLを知る利用者はログインなしで操作できます。
3名簿を確認・移行する
  • ログインせずに団員名簿を開く
  • 旧形式の名簿がある場合、members_v2へ一度だけ自動移行される
  • 以後は追加・修正・削除のたびに団員単位でクラウド保存される
  • 旧データのmembersは自動削除しないため、確認後にバックアップとして保管または手動整理する
名簿画面に「Firebaseと同期済み」と表示されれば完了です。
